How it works

A fast, predictable pipeline handles most invoices. The agent steps in only when the checks fail, so you get speed and reliability.

1

Read the page

Text and layout from digital PDFs, or OCR for scans and photos.

2

Extract with AI

A vision-language model fills a strict schema: fields, parties, line items, totals.

3

Verify with code

Every value is checked against the document. No check, no acceptance.

4

Agent fixes failures

An AI agent re-reads the page and corrects what failed, or sends it to a person.

What gets checked

The AI proposes, code verifies, and people resolve disagreements. The system never guesses silently.

Arithmetic

Line amounts, subtotal, discounts, taxes, shipping and round-off must add up to the total.

Grounding

Every extracted value must actually appear on the page, next to the right label.

Formats & IDs

Tax ID checksums (e.g. India GSTIN), date order, currency and document type.
